# OpportHunters

A single-page job-match assessor. Paste a current job listing and it ranks the fit as **Very High / High / Mid / Low** against your profile, shows matched strengths and gaps, and suggests how to tailor the application. It also keeps a tracker of the roles you've assessed.

Everything runs in the browser. Listings and the tracker are stored in your browser's localStorage only.

Open `index.html` directly, or enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
